# 🎯 Number Guessing Game in C

A simple terminal-based number guessing game written in C.

## 🚀 Features
- Random number generation
- Multiple difficulty levels
- Limited attempts
- Replay option

## 🛠️ Technologies Used
- C Language
- GCC (MinGW)

## ▶️ How to Run

```bash
gcc src/main.c -o game
./game
